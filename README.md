## 🛠️ Rapid Setup Guide for GitHub Pages

1. **Create Repository:** Create a new repository on your GitHub account named `yourusername.github.io` (replace `yourusername` with your actual GitHub username).
2. **Upload Files:** Upload both the `index.html` file and this `README.md` file directly into the root level of your repository branch (`main`).
3. **Activate Deployment:**
   * Go to the **Settings** tab of your repository.
   * Under the left sidebar menu, select **Pages**.
   * Set the deployment source option to **Deploy from a branch**.
   * Under the **Branch** dropdown, select `main` (or `/root`) and click **Save**.
4. **Go Live:** Within 1-2 minutes, GitHub will generate a live address link at: `https://yourusername.github.io`
